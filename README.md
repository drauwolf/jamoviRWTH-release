# Project jamovi.RWTH (2021-2026+)

## Description

This repository has the source code for the project **jamovi.RWTH**, featuring an add-on module to the open statistical software [jamovi](https://www.jamovi.org).

It is designed specifically for teaching of statistical methodology and improving data literary at different levels (e.g. university or high school education). The project **jamovi.RWTH** features statistical analyses from the book "Grundlagen der Wahrscheinlichkeitsrechnung und Statistik" by E. Cramer and U. Kamps (2020) and can be used for practicing and learning statistical methodology without coding. 
The referenced book is published in Springer Nature and is available under the following link: https://link.springer.com/book/10.1007/978-3-662-60552-3.


## Usage and Starting Guide

jamoviRWTH is an add-on module for jamovi which combines all analyses in the chapters *Descriptives* and *Inference* of the book "Grundlagen der Wahrscheinlichkeitsrechnung und Statistik" by E. Cramer and U. Kamps (2020).  jamoviRWTH can also be installed as an R package. 

A short starting guide for jamoviRWTH in German is available [*here*](https://github.com/drauwolf/jamoviRWTH/blob/main/Anleitung_2026.08.31.pdf). For an english starting guide to jamovi (or other languages), please refer to https://www.jamovi.org/getting-started.html and https://docs.jamovi.org/.

## Contents of the Module jamoviRWTH

##### **Descriptives**

This block features analyses in the area of descriptive statistics (short: *Descriptives*) corresponding to chapters A1-A9 of the book. It contains 
- Tables and Graphs (A2), 
- Measures of Central Tendency and Dispersion (A3),
- Grouped Data and Histrograms (A4),
- Measures of Concentration (A5),
- Index Numbers (A6),
- Measures of Correlation and Dependence (A7),
- Regression Analysis (A8) and
- Time Series Analysis (A9).

##### **Inference**

This block features methods of statistical inference (short: *Inference*) corresponding to chapters D3-D7 of the book. It contains
- Maximum Likelihood Estimation (D3/D5),
- Confidence Intervals (D4/D5),
- Statistical Tests (D6) and
- Linear Regression (D7).

##### **Data Library**

All examples with data from chapters A and D of the book "Grundlagen der Wahrscheinlichkeitsrechnung und Statistik" by E. Cramer and U. Kamps (2020) can be found in the Data Library of the module jamoviRWTH.
